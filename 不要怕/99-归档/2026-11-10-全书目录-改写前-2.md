# 《不要怕》全书目录

这页管理候选篇目、写作状态和阅读顺序，也为作者按问题回看自己的经历与认识提供入口。框架随真实篇目逐步填写；这里的表格不是最终印在书里的目录。

## 篇目清单

每篇占一行。还没有确定顺序的篇目，顺序栏写“待编排”；尚未形成正文时，可以先链接到原始素材。

| 阅读顺序 | 篇名与文件链接 | 状态  | 主题线索 | 素材来源／编排备注 |
| ---- | ------- | --- | ---- | --------- |
|      |         |     |      |           |

状态约定：

- **待写**：已有想法或素材，尚未形成正文。
- **初稿**：已写出一版正文，仍在发展。
- **修改中**：正在调整叙述、结构或表达。
- **暂定稿**：当前阶段可以作为阅读稿，后续仍可修订。

空白模板和格式示例不计入篇目清单。篇目撤下时，正文存入归档，并在对应条目的备注中写明“暂时撤下”、更新文件链接，阅读顺序改为“—”。

目前留空，随真实篇目积累再补充。文章中的认识发生变化时，同步核对这里的提示；未被作者确认的编辑解释留在协作记录中，不列为作者已有的认识。

## 分部与阅读顺序

分部暂未确定。积累几篇可读文章后，观察反复出现的人物、处境、感受和认识的变化，再提出编排建议，在这里记录作者采纳的顺序。

## 编排笔记

在这里记录文章之间的呼应、可能的分组、需要补充的过渡，以及尚未采纳的建议。

## 怎样添加或修改篇目

1. 新建文章后，在上方清单登记一行；暂时不知道主题或顺序的栏目可以留空。
2. 给篇名加上相对文件链接。从本页链接正文时，格式可参考下面的示例，并替换成实际存在的文件名。
3. 文章改名或移动后，核对并更新对应条目和链接；修改进展变化时，更新状态。清单、状态与阅读顺序由作者或助手维护。
4. 阅读顺序以本页为准，不需要为了排序给正文文件加章节编号。
5. 文章中有适合日后重读的认识时，再补充“按问题回看”索引；不为填表替作者归纳尚未形成的结论。
