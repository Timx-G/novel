| 展开位置 | 这一部分要带来的内容 | 依据 |
| --- | --- | --- |
| 起笔 | 对忙着下一件事、来不及回看的生活现象的观察 | 作者本轮补充，按个人观察表达 |
| 落到自己 | 转专业、保研、求职中的持续向前，以及想表达却说不清的触发 | 原始材料；梦境保留不确定性，不补造现场 |
| 反思 | 重新追问当时在意什么、怎样选择、如今看法有没有变化 | 作者认可的主干，尚未有答案的部分保留为问题 |
| 写下来的理由 | 希望记录成长中的经历、感受与思考，日后还能回看，认识变化后继续补写 | 原始材料与 Mission |
| 暂定落点 | “不要怕”对自己的意义：希望今后遇到困难时，有勇气面对 | 作者已确认的主旨；不写成保证或已完成的改变 |

## 4. 后续待办（不属于 v0.1 的完成条件）

- 接收作者对完整初稿的口吻、详略和情绪分寸的反馈，明确下一轮需要改什么。
- 收到更具体的经历后更新前文；先判断新材料影响本篇还是多个篇目，在下一轮 Plan 中列明范围。
- 进入下一章时为那一章建立 Spec；回头修订本篇时，更新已有 Spec，不另建互相分叉的正文与要求。
- 上一轮合并后，从最新 main 建立新的修订分支；沿用本篇文件路径，记录新一轮目标与核对结果。
- 重大改写先保存完整旧稿；作者明确认可的全书偏好再同步到全局表达约定。

“暂定稿”仍由作者认可或明确授权决定。本篇可以在别的章节已经开始后继续修订。
