# 阅读版｜排版与自动导出

本轮目标：把已选封面和实际正文排成个人 PDF 阅读本，以后每次本地 main 整合后刷新对应版本。此 Spec 管理呈现，不替代章节写作 Spec，不把排版完成记为文章定稿。

## 范围与选择

- 来源：[封面 v0.3](../03-附件/封面/不要怕-封面-v0.3.png)、[全书目录](../00-全书规划/全书目录.md)与所指正文。当前只有《为什么要把这些写下来》一篇；待写篇目不进入阅读本。
- 输出：封面、扉页、可点击目录、正文、章末注和页码。原文照排，不添加署名或出版信息。
- 本轮采用 PDF 固定版式；网页、EPUB、Word 不在本轮范围。
- 编辑实现选择：140×210 mm、嵌入宋体、11 pt 正文、暖白纸色。设计仍可依据阅读反馈调整。
- [版式配置](reading-edition.json)属于本书；通用流程见[book-reading-edition](../.agents/skills/book-reading-edition/SKILL.md)。书内入口是相对符号链接，与项目根目录共用一份 skill。

## 迭代与自动化

旧章修订或新章写作先由 `life-writing` 与章节 Spec 完成，再同步目录；阅读版重排所有已纳入篇目。初稿可以进入阅读本，尚无正文的选题不能进入。

功能分支按需预览。获授权合入 main 后，项目钩子自动运行排版脚本，从准确提交读取输入，按提交号保存阅读版；助手继续执行视觉核验。运行脚本不等于自动启动 AI 或作者认可文字效果。

触发、失败恢复与依赖见[自动导出说明](../.agents/skills/book-reading-edition/references/automation.md)。失败保留上一成功文件，标识本次失败。当前 `codex/why-write-spec` 分支按作者要求不合入。

## 当前样本与验收

样本：[不要怕-阅读样本-v0.1.pdf](../04-导出/不要怕-阅读样本-v0.1.pdf)，[来源与检查记录](../04-导出/不要怕-阅读样本-v0.1.json)。阅读样本版本与正文版本分开管理。

- 自动检查：核对 JSON 中篇目、输入散列、文字完整性、边界与导航。
- 视觉检查：最终 PDF 渲染后逐页检查，实际结果记在 JSON 的 `visual_review`；未完成时保持 pending。
- 自动触发检查：临时仓库验证旧章更新、新章收录、普通/快进/压缩合并、冲突解决和失败保留旧版，不对实际分支测试合并。
- 内容验收：正文仍是初稿；排版可用不代表文章已获作者认可。阅读意见经授权落实到正文与章节 Spec。

正文、原始素材、封面原图与 Obsidian 配置在本轮排版中保持原貌。合入状态以实际 Git 状态为准。

2026-11-11 实际核验：样本 6 页，逐页检查完成；宋体已嵌入，目录指向正文第 1 页，全文提取与来源一致。12 项隔离仓库测试通过，涵盖预览、提交快照、合并触发、冲突、rebase、长段跨页、中文标点、改名重排、既有撤下规则及失败保留旧版。独立接续验证也完成了旧章修订和新增篇目的实际导出。Skill 元数据与相对入口有效，活动 Markdown 的 150 个本地链接有效。本仓库已配置 `.githooks`；实际分支未合入，main 未改变。以上验收针对呈现流程，不代表初稿内容定稿。
