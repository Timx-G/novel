# Mission｜《不要怕》为什么写

依据：作者于 2026-11-10 对书名、写作目的与首批篇目的确认。本文件维护全书目标与边界。

## 对自己说的话

“不要怕”是作者对自己说的。

把人生中遇到的人、经历、困难和挫折写下来，也把当时的感受、后来的思考和仍未解开的疑问留下来。希望未来面对问题时，能够从自己的文字里获得提醒，有勇气继续面对生活。

这是一种持续的自我提醒。写作应允许真实的害怕、犹豫、失误和暂时无解；已经走过的困难可以回看，尚未克服的困难如实记录。

## 写给谁、写成什么

- 首先写给现在与未来的自己。作者于 2026-11-10 明确当前作为个人书籍保存和阅读，不计划直接公开发表或销售；日后是否分享再由作者决定。
- 沿用真实故事与随笔集的定位。可以有小说般的叙事感，事实仍以作者提供的真实材料为依据，默认不虚构。
- 记录成长、爱情、关系、学习、工作与日常生活。题材由实际经历生长，不要求每篇都讲挫折或得出道理。
- 先独立成篇，再按真实篇目形成分部和顺序。首批获认可的五个候选篇目见[全书目录](../00-全书规划/全书目录.md)，篇名暂定，名单不是全书篇数上限。

## 写作要实现的事

1. 保存经历的来处：让未来的自己看得懂当时发生了什么、为什么会那样想。
2. 梳理自己的认识：分清当时的想法、现在的回看，以及尚未得到回答的问题。
3. 留下可以回看的提醒：记录做过什么、哪些尝试在什么条件下起过作用；情况变化时允许修订。
4. 逐篇形成有自己口吻的文字，再通过持续修改积累成书。

## 当前范围与边界

- 依据 Mission、表达方式与 Roadmap 逐篇推进；每轮约定可交付的范围，初稿可以先形成，后续材料与认识继续修订前文。
- 首批内容使用已有[素材](../01-素材.md)和作者的后续补充。缺少的细节保留疑问，可以先写短稿。
- 麦扣老师、佛道儒与科技公共事件等线索，待作者提供相关材料后再讨论是否成篇；不提前编写内容。
- 篇目由作者决定。助手提出的题目与解释标为建议，作者未采纳的内容不自动成为章节。
- 不设固定字数、篇数或出版期限；未形成稿件的计划、提纲和 Spec 不计为作品。

## 怎样判断写作有进展

- 文字忠于作者提供的经历与立场，能够区分事实、感受、听闻和推测。
- 作者读起来能认出自己的意思与口吻；认识尚未形成时，疑问表达清楚也有价值。
- 已有稿件可以找到材料依据、当前版本和下一步；重要修改能够回看旧稿。
- 已形成的经验保留适用情境，不将一次结果写成对所有困难的保证。

文风是否合意需要通过实际稿件与作者反馈判断，框架建好不等于作品已经完成。
