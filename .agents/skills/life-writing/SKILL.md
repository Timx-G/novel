# 人生故事与随笔成书

把作者的想法、回忆与原稿整理成普通读者能理解的原创中文作品。保留原意、事实层次和作者口吻，按素材选择结构与篇幅。默认不虚构；写作效果通过真实稿件和作者反馈逐步校准。

## 接续当前作品

1. 根据用户指定的文件或项目入口确定书籍目录，先读该书的 `AGENTS.md`。
2. 读取书籍的开始说明、写作方向、全书目录和协作记录，再读本次相关的原稿与素材。只读取任务需要的附件；用户指定的散落笔记同样是有效输入，不擅自搬家。
3. 分清本轮请求：讨论或评价、在回复中起草、修改指定文件、保存新篇目、整理全书。仅讨论时只回复；贴来的文字未要求保存时，在回复中交稿。已明确授权的文件编辑直接完成。

缺少某份规划文件时，利用现有上下文继续；只有本轮要求建立或补充框架时才创建相应文件。书籍约定与作者当前要求优先于本 skill 的默认方式。

## 按输入开展工作

| 输入与请求 | 本轮应交付的结果 |
| --- | --- |
| 零散想法、感受或总结 | 梳理原意；仅对影响立意的歧义集中追问少量问题。意思清楚就按要求整理，可以很短。 |
| 真实经历或故事片段 | 理清人物关系、时间顺序、事件变化及当时与现在的感受，按材料组织文章或提出结构建议。 |
| 已有文章 | 按指定幅度编辑。未要求大改时，以澄清表达和修正明显问题为主，保留立场、节奏及有意义的含混。 |
| 多篇文章 | 检查重复、人物称呼、时间与观点的关系，提出分组和顺序；按作者已采纳的决定更新目录。 |
| 尚无素材或仅要求框架 | 说明当前状态，维护获授权的框架与待办。正文和篇目清单留空，不把模板、示例或建议计为作品。 |

材料不足且作者要求直接写、不追问时，交付现有材料能支撑的短稿，必要的缺口在正文外简短说明。不要用新增立场或重复解释满足字数目标。

## 理解与事实边界

- 区分亲历、回忆、听闻、感受、推测和编辑建议。核对谁知道什么、判断来自哪里，保留否定、条件、时间与不确定性。
- 感受只有一句时，不替作者确定未说出的原因、态度或人生结论。需要在几种解释中作选择才能成文时，先澄清；无需选择就能短写时直接写。
- 不补造真实人物的经历、对白、关系、动机、心理、日期或地点。原话记不准时使用有依据的转述，不能改写成精确引语。
- 相互冲突的记述并列保留，指出具体矛盾；未确认是同一事件时，不自行合并。把必要疑问放在回复或获授权维护的协作记录中，不混进正文充当作者原话。
- 发现错误前提、逻辑跳跃或故事不足以支持结论时，指出依据和可行改法。审美判断标为建议，不默认附和，也不把个人经验扩成普遍规律。
- 他人的文字和观点保留来源归属；需要作为引文或公共事实使用时按需核对。查到的公开资料不能变成作者亲历。
- 作者明确要求虚构或改编时，说明该篇性质并保留真实材料与创作部分的区别；不据此改变整本书的性质。

## 组织与改稿

起草、结构调整或多篇编排时，按需读取[编辑指南](references/editing-guide.md)的相应部分。轻度润色只使用确实相关的规则。

让人物、动作、观点和前后关系具体清楚。按内容安排长短与详略，保留必要的心理活动、感慨和留白。故事与思考可以各自成篇，不要求每篇都以故事证明一个道理。

保留原文中自然且有作用的重复、标点和句式。不给文章设置机械禁词表，不强制反转、悬念、首尾呼应或升华结尾，也不把所有长句切成短句。使用朴素、具体等可说明的风格特征形成原创表达。

交稿前对照素材，检查有没有新增事实、替换立场、强化确定性、漏掉重要限制，或把当下的理解写成当年已经知道。再检查段落是否推进、指代是否清楚、心理与动作是否重复、文章是否已经可以结束。

## 文件与持续迭代

- 遵循书籍的文件、状态、归档和链接约定。原始素材保留原貌；素材文件不因正文润色而被覆盖。
- 结构重排、大幅删减或叙述角度变化前，完整保存旧稿，确认副本存在后再改。归档位置与命名见书籍约定；同名副本增加序号。
- 一篇正文维护一个主要文件。新建、改名、撤下或重新编排后，同步目录条目、状态和相关链接；模板及编辑说明不计为正文。
- 在获授权的文件编辑完成后，按实际变化同步协作记录：本次改动及原因、涉及的素材与稿件、未解决问题、下一步。没有新决定或改动时不写空日志。
- 作者明确认可的表达偏好记录为已确认；助手的提议记录为建议。只适用于某篇的反馈留在书籍项目，不自动改成通用 skill 规则。
- 作者要求根据反馈调整通用方法时，修改对应规则并说明依据，不把整篇私人素材或人物资料复制进 skill。

## 交付

在回复中起草时，交付所需的文字，只有影响理解的疑问才另作简短说明。完成文件修改时，提供文件入口，说明主要改动、原因和仍需确认的事实。只评价时，给出具体问题和修改方向。

核对实际文件、链接与归档后再报告完成。框架核验只说明框架可用；不据此宣称文风成熟、达到出版水平，或已配置备份、同步和自动导出。
