一部持续写作中的真实故事与随笔集，首先写给现在与未来的自己。“不要怕”是面对经历、困难和挫折时，留给自己的提醒。

每天保存一份原始草稿，先一起讨论，再根据内容补充已有篇章或写成新篇。素材按日期积累，正文按主题组织；目前已有三篇初稿，其余篇目随材料推进。
